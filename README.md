# 🗳️ ফর্ম-১৩ | ভোটার এলাকা স্থানান্তর আবেদন (অটো-ফিল)

**Bangladesh Election Commission – Form 13 Auto-Fill & PDF Generator**

> বাংলাদেশ নির্বাচন কমিশনের **ফর্ম-১৩** (এক ভোটার এলাকা হইতে অন্য ভোটার এলাকায় ভোটার স্থানান্তরের আবেদন) অনলাইনে পূরণ করুন এবং PDF হিসেবে ডাউনলোড করুন।

## ✨ ফিচার সমূহ

- ✅ **লাইভ অটো-ফিল** — বাম পাশে টাইপ করলেই ডান পাশের ফর্মে সঙ্গে সঙ্গে দেখা যায়
- ✅ **হুবহু অফিসিয়াল ফর্ম** — নির্বাচন কমিশনের ফর্ম-১৩ এর অনুরূপ লেআউট (২ পেজ)
- ✅ **Select2 ড্রপডাউন** — বাংলায় সার্চ করে জেলা বাছুন
- ✅ **ডিপেন্ডেন্ট উপজেলা** — জেলা সিলেক্ট করলে স্বয়ংক্রিয়ভাবে সেই জেলার উপজেলাগুলো লোড হয়
- ✅ **৬৪টি জেলা + সকল উপজেলা** অন্তর্ভুক্ত
- ✅ **PDF ডাউনলোড** — ব্রাউজারের Print → Save as PDF দিয়ে সহজেই PDF করুন
- ✅ **রিসেট বাটন** — এক ক্লিকে সব তথ্য মুছে ফেলুন
- ✅ **GitHub Pages রেডি** — কোনো ব্যাকএন্ড/সার্ভার লাগে না

## 📋 ফর্মে যা যা আছে

### পেজ ১
| ক্রমিক | বিষয় |
|--------|-------|
| প্রাপক | উপজেলা/থানা নির্বাচন অফিসার |
| ১ | আবেদনকারীর নাম |
| ২ | জাতীয় পরিচয়পত্র নম্বর (NID) |
| ৩ | জন্ম তারিখ |
| ৪ | বর্তমান তালিকাভুক্তি সংক্রান্ত তথ্যাদি |
| ৫ | যে এলাকায় স্থানান্তর হইতে ইচ্ছুক (পোস্ট কোড বক্সসহ) |
| ৬ | বর্তমান ঠিকানায় অবস্থানকাল |
| ৭ | স্থানান্তরের কারণ |

### পেজ ২
| বিষয় |
|-------|
| ৮. সংযুক্ত দলিলাদির তালিকা (ক, খ, গ) |
| আবেদনকারীর স্বাক্ষর/টিপসহি বক্স |
| সনাক্তকারীর নাম, NID ও ঠিকানা |
| অফিস ব্যবহারের অংশ |
| প্রাপ্তিস্বীকার পত্র |

## 🚀 ব্যবহার পদ্ধতি

### অনলাইনে (GitHub Pages)
সরাসরি লিংকে গিয়ে ফর্ম পূরণ করুন।

### লোকালি চালান
```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/mehdiakram/form-13-voter-migration.git

# ফোল্ডারে যান
cd form-13-voter-migration

# index.html সরাসরি ব্রাউজারে খুলুন
# অথবা যেকোনো লোকাল সার্ভার ব্যবহার করুন
```

### PDF তৈরি করুন
1. ফর্মে সব তথ্য পূরণ করুন
2. উপরে **"⬇ PDF ডাউনলোড / প্রিন্ট"** বাটনে ক্লিক করুন
3. ব্রাউজারের প্রিন্ট ডায়ালগে **"Save as PDF"** বা **"Microsoft Print to PDF"** বেছে নিন
4. **Save** করুন
